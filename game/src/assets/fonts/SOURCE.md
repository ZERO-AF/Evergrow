# Metamorphous — display serif (registered as `Evergrow Display`)

Designer: Sorkin Type Co (www.sorkintype.com). Reserved Font Name "Metamorphous".

Copyright (c) 2011-2012 by Sorkin Type Co.

Bundled unmodified static Regular font under the SIL Open Font License 1.1. Metamorphous is a
Morpheus-adjacent fantasy serif; it serves headings, nameplates, banners and all canvas display
lettering. The original binary is renamed locally for a simple asset URL; its internal font data
is unchanged.
